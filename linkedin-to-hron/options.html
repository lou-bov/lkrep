LinkedIn → HR-ON settings

Opened when the job's applicant list isn't known yet. Each job's applicant list is remembered once you've opened it with the extension. HR-ON requires an e-mail. This address is used for every candidate. Leave empty to use the candidate's own e-mail. Comma-separated. Pre-filled for every new candidate; you can change them per candidate. Only needed if a field isn't found automatically. Right-click the field in HR-ON → Inspect, and use e.g. its name. Keys: name, address, city, country, email, mobile, phone, notes, tags, cv.
